# Quickstart: 基底画面のページ表示部フラット化

## 目的

基底画面のページ表示部がカード状の外枠を持たず、本文がそのまま表示されることを確認する。

## 確認手順

1. リポジトリルートから frontend に移動する。
2. `yarn dev` を起動する。
3. ダッシュボード、カード一覧、復習、設定を順に開く。
4. 各画面で、ページ表示部の外側に白背景の独立カード、角丸、影付き、中央寄せ固定幅の枠がないことを確認する。
5. 見出し、本文、フォーム、一覧、空状態メッセージが、ページ表示部に直接表示されていることを確認する。
6. 必要に応じて `yarn build` を実行し、既存ビルドに影響がないことを確認する。

## 合格条件

- 主要4画面すべてで、外枠カードが消えている
- 画面遷移と業務機能は従来どおり動作する
- レイアウト変更以外の差分が発生していない
