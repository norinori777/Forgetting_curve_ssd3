# Quickstart: 基底画面

## 前提

- Node.js と依存関係がインストール済みであること
- `frontend` の開発環境が起動できること

## 起動

```bash
cd frontend
yarn dev
```

## 確認手順

1. ブラウザでダッシュボードを開く
2. 画面上部にサービス名表示部とメニュー部が表示されることを確認する
3. サービスカード一覧、復習、設定の各リンクを押して、ページ表示部が切り替わることを確認する
4. リロード後にページ表示部の初期表示がダッシュボードになることを確認する

## テスト

```bash
cd frontend
yarn test
yarn lint
yarn typecheck
```

## 期待結果

- 初期表示でヘッダーとダッシュボードが表示される
- ヘッダーリンク操作でページ表示部だけが切り替わる
- 共通ヘッダーが全画面で一貫して表示される
