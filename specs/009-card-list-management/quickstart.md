# Quickstart: UC-13 カード一覧確認・検索・一括管理

## Goal

カード一覧画面で自分のカードを確認し、検索・絞り込み・複数選択・一括ラベル付与・削除・エクスポートができることを確認する。

## How to Verify

1. backend と frontend を起動する。
2. ログイン済み状態で `/cards` を開く。
3. カード一覧が自分のデータだけで表示されることを確認する。
4. タイトル・問い・答えのいずれかで検索し、絞り込み条件を追加する。
5. 検索結果が 0 件になった場合、空状態メッセージと条件クリア導線が出ることを確認する。
6. 複数カードを選択し、一括で分類語を付与する。
7. 一覧の下端までスクロールして、追加読み込みで閲覧が継続することを確認する。
8. 個別編集・削除の導線と、JSON エクスポートの導線が表示されることを確認する。

## Suggested Checks

- frontend のページテストで、CardListPage が静的文言ではなく実データ表示前提の構造になっていることを確認する。
- backend のカード一覧 API で、所有者制御・検索・カーソルページング・一括更新が正しく動作することを確認する。
- エクスポート結果が JSON 単一ファイルとして出力されることを確認する。

## Expected Outcome

- 自分のカードだけが表示される。
- 検索条件を組み合わせて対象を絞り込める。
- 複数選択したカードに対して一括付与できる。
- 下端到達時も一覧閲覧を継続できる。
- 空状態から一覧へ戻れる。
