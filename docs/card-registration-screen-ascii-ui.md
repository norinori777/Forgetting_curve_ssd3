# Card Registration Screen (SCR-05) ASCII UI

## Overview
SCR-05 は学習カードの登録・編集を行う画面です。個別登録またはインポートの２つのモードをタブで選択でき、各入力項目は文字数制限付きです。

## 4. 重複送信防止機能

### 4-1. ボタン非活性状態（連続クリック防止）

```text
+----------------------------------------------------------------------------+
|  ※ 同一操作の重複送信を防ぐため以下を実装します：                          |
|                                                                            |
|  - API 送信時は、送信側でリクエストボタンを非活性化                         |
|  - クライアント側で 2 回目以降の送信要求をブロック                          |
|  - API 側でも冪等制御（前回と同一リクエストなら同じ結果を返す）を実装        |
|  - サーバー側でも重複作成をチェックして防止する                             |
|                                                                            |
|  画面上の見た目:                                                           |
|                                                                            |
|  +--------------------------+  +--------------------------+                |
|  | 初回復習日を確認する      |  |      保存する           |                |
|  +--------------------------+  +--------------------------+                |
|  （クリック判定あり）           （クリック判定あり）                        |
|                                                                            |
|  ↓ 1回目クリック                                                           |
|                                                                            |
|  +--------------------------+  +--------------------------+                |
|  | 初回復習日を確認する      |  |      保存する           |                |
|  | （非活性）               |  | （非活性）              |                |
|  +--------------------------+  +--------------------------+                |
|  （以降のクリックは無視される）    （以降のクリックは無視される）            |
|                                                                            |
+----------------------------------------------------------------------------+
```

## 6. 入力制限と文字数カウンター

| 項目 | 必須 | 最大文字数 | 説明 |
|------|------|-----------|------|
| タイトル | ✅ | 100 | カードの短いラベル |
| 問い | ✅ | 500 | 復習時に表示される質問 |
| 答え | ❌ | 500 | 問いに対する回答 |
| メモ | ❌ | 500 | 追加の補足情報 |

---

## 7. エラーメッセージ種別

| 種別 | メッセージ例 | 対応 |
|------|-----------|------|
| バリデーション | タイトルは必須です。 | フィールドに赤線表示、エラーテキスト |
| 通信エラー | ネットワーク接続を確認してください。 | 再試行ボタン表示 |
| JSON スキーマエラー | JSON スキーマが無効です。 | 別ファイル選択促促促促促促進 |
| バージョン不一致 | サポートされていないバージョンです。 | 推奨バージョン情報表示 |
| ID 衝突 | 2 枚のカードが新規 ID で取り込まれました。 | 完了画面で衝突数を表示 |

---

## 8. 受け入れ基準チェックリスト

- [ ] 個別登録とインポートをタブで切り替え可能
- [ ] タイトル、問い は必須フィールド
- [ ] 答え、メモ、タグは任意フィールド
- [ ] 文字数カウンターは リアルタイムで更新
- [ ] タイトル 100 字超過、問い 500 字超過で入力不可
- [ ] 保存ボタン押下時に入力検証を実施
- [ ] バリデーションエラー時はデータ保存せずエラー表示
- [ ] 初回復習日確認画面で復習スケジュール表示（1 日後、1 週間後、2 週間後、1 か月後）
- [ ] 送信中はボタン非活性化
- [ ] 重複送信時は 1 件のみ作成
- [ ] 通信失敗時は再試行導線を提供
- [ ] インポート時に JSON スキーマ・バージョン検証を実施
- [ ] インポート時に ID 衝突を検知し、衝突レコードは新規 ID で再採番
- [ ] インポート成功時に結果サマリーを表示（成功数、衝突数、失敗数）
- [ ] 他ユーザーコンテキストでのアクセスは 403 で拒否
